Відформатуй усі HTML, CSS і JavaScript файли проєкту. Не змінюй
функціональність, тексти, URL, структуру DOM, CSS-значення, порядок правил,
класи, ID, назви змінних або дизайн. Не додавай бібліотеки та не видаляй код.

Використовуй наявну конфігурацію Prettier. Якщо її немає — створи
.prettierrc.json з такими правилами:
- printWidth: 80
- tabWidth: 2
- singleQuote: true
- trailingComma: all
- htmlWhitespaceSensitivity: css

HTML:
- 2 пробіли для відступів.
- Вкладені елементи розміщуй з нового рядка.
- Короткі теги та невелику кількість атрибутів лишай в одному рядку.
- Довгі теги або теги з кількома атрибутами перенось читабельно.
- Додавай один порожній рядок між незалежними sibling-елементами.
- Не розділяй тісно пов’язані конструкції: <li> одного списку,
  inline-текст зі <span>/<b>, <br> у тексті та пов’язані meta-теги однієї групи.

CSS:
- Один селектор або логічно пов’язана група селекторів на правило.
- Кожна властивість з нового рядка, 2 пробіли для відступів.
- Один порожній рядок між правилами.
- Розгорни стиснені правила та @media.
- Не змінюй порядок правил, селекторів чи значень.

JavaScript:
- 2 пробіли для відступів.
- Одинарні лапки, якщо це не змінює значення рядка.
- Пробіли навколо операторів і читабельні переноси довгих виразів.
- Не переписуй вирази в інші конструкції, навіть якщо вони еквівалентні.

Після форматування:
1. Запусти Prettier у режимі перевірки для HTML, CSS і JS.
2. Запусти node --check для JavaScript.
3. Запусти git diff --check.
4. Покажи короткий список змінених файлів і результати перевірок.
